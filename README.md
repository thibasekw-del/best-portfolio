# BEST. Portfolio

เว็บไซต์ Portfolio ส่วนตัวของ BEST นักศึกษาสถิติจาก KMITL
สำหรับแนะนำตัว แสดงทักษะ และนำเสนอผลงานด้าน Data และ Software Development

## เทคโนโลยีที่ใช้

- Next.js และ React
- TypeScript
- Tailwind CSS และ CSS
- Lucide Icons
- Vercel สำหรับ Deploy

ออกแบบให้รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ
